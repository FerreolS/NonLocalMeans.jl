NonLocalMeans.nonlocalmeans! — Method
nonlocalmeans!(output, value[, precision]; patch = 2, neighborhood = 7,
              h = 1, channel_dim = nothing,
              selected_area = nothing, output_precision = nothing)

In-place version of nonlocalmeans. Inputs aliasing output are copied first.

When output_precision is provided, it is filled with the estimated precision of each output sample, (Σ pⱼwⱼ)² / Σ pⱼwⱼ², treating the weights as fixed. The return value is output unless output_precision is supplied, in which case it is (output, output_precision).

channel_dim has the same meaning as in nonlocalmeans. selected_area restricts valid patch and search locations to the supplied spatial subset.

NonLocalMeans.nonlocalmeans — Method
nonlocalmeans(value[, precision]; patch = 2, neighborhood = 7, h = 1,
               store_precision = false,
              channel_dim = nothing, selected_area = nothing)

Apply non-local means denoising to an N-dimensional real-valued array using KernelAbstractions.jl.

patch is the patch radius: an integer (same in every dimension), a Tuple of integers, or a CartesianIndex with one radius per dimension. neighborhood defines the search window and accepts the same radius forms, or a CartesianIndices of offsets relative to each sample, e.g. CartesianIndices((-2:2, 0:3)) for an asymmetric window.

If precision is supplied, it weights the patch distances and is used to compute the denoising weights. When precision is omitted, a unit precision array is used and only output is returned unless store_precision = true. With an explicit precision, the function returns (output, output_precision); output_precision is nothing unless store_precision = true.

selected_area optionally restricts the denoising to a subset of spatial positions; pass nothing (default) to use the full spatial domain or a CartesianIndices/array of CartesianIndexs to limit the valid search and patch locations. The weights are exp(-patch_distance / h), where patch_distance is the precision-weighted mean squared difference between patches.

Inputs must use one-based indexing. If channel_dim is an integer, that permutation is treated as the channel axis and denoised jointly using a single set of weights; patches and search windows then span the remaining dimensions. precision and any returned precision array have the same size as value (one precision value per channel and sample). With channel_dim = nothing (default), all dimensions are spatial.
